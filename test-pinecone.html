🧪 Test Pinecone Integration

⚠️ Setup Required

Before testing, you need to add your Supabase anon key:

  1. Go to: Supabase API Settings
  2. Copy the anon public key
  3. Open this HTML file in a text editor
  4. Replace YOUR_ANON_KEY_HERE with your actual key (around line 107)
  5. Save and refresh this page
